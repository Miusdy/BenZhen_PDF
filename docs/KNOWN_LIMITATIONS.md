# 已知限制

## 已实现并验证

- 文字型 PDF 的提取、页分类、质量评分、简单双栏顺序、标题/列表/脚注启发式识别；
- PyMuPDF 表格探测与图片提取；
- 关键数字、日期、金额、百分比、账号、编号、URL 和邮箱冲突检测；
- 版本化 IR、页码/坐标追溯、DOCX 黄色核对标记、JSON/HTML 报告；
- 加密 PDF、中文/空格路径、空白页、取消不生成伪成功 DOCX；
- sidecar JSON Lines 协议与桌面 UI 的暂停、继续、取消入口。
- macOS Apple Silicon sidecar、Tauri release 构建、未签名 `.app`/`.dmg` 生成与原生启动。

## 已实现但依赖环境验证

- Tesseract OCR 与 OpenCV 预处理：安装真实 OCR 运行时被本机尚未接受的 Xcode 许可门禁阻止，真实中文扫描 OCR 尚未在本机端到端通过；
- macOS Apple Silicon DMG 已构建并启动，但当前本地测试包不含可再分发 OCR runtime，不能作为完整扫描版正式发行；
- macOS Intel 与 Windows MSI/EXE 构建配置：需要目标机和经过许可证审核的目标平台 OCR runtime。

## 尚未达到的高级能力

- OCR 目前按整页执行，尚未做可靠的低质量区域级 OCR 与逐块几何对齐；
- 复杂无边框表格、嵌套表格、数学公式、竖排文字和任意多栏版式可能退化为坐标顺序并需要核对；
- DOCX 使用紧邻提示和黄色底纹，尚未写入原生 Word 批注对象；
- 跨页段落合并和图片说明关联采用保守策略；
- 动态 OCR 并发目前配置安全上限，但核心按页串行以降低内存峰值；
- 自动更新未实现；在签名基础设施完成前不会提供不安全更新。

任何限制都不允许静默丢页：无法提取的可见页面会进入报告并在 Word 中留下核对提示。
