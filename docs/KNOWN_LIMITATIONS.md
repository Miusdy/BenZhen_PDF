# 已知限制

## 已实现并验证

- 文字型 PDF 的提取、页分类、质量评分、简单双栏顺序、标题/列表/脚注启发式识别；
- PyMuPDF 表格探测与图片提取；
- 关键数字、日期、金额、百分比、账号、编号、URL 和邮箱冲突检测；
- 版本化 IR、页码/坐标追溯与 DOCX 黄色核对标记；
- 加密 PDF、中文/空格路径、空白页、取消不生成伪成功 DOCX；
- sidecar JSON Lines 协议与桌面 UI 的暂停、继续、取消入口。
- macOS Apple Silicon sidecar、Tauri release 构建、完整 ad-hoc 签名 `.app`/`.dmg` 与包内中英文 OCR。

## 已实现但依赖环境验证

- macOS 发行包采用 ad-hoc 签名且未提交 Apple 公证，首次打开必须由用户在“系统设置 → 隐私与安全性”中明确确认；这是免费发布策略的已知限制；
- macOS Intel 与 Windows MSI/EXE 构建配置：需要目标机和经过许可证审核的目标平台 OCR runtime。

## 尚未达到的高级能力

- OCR 目前按整页执行，尚未做可靠的低质量区域级 OCR 与逐块几何对齐；
- 复杂无边框表格、嵌套表格、数学公式、竖排文字和任意多栏版式可能退化为坐标顺序并需要核对；
- DOCX 使用紧邻提示和黄色底纹，尚未写入原生 Word 批注对象；
- 跨页段落合并和图片说明关联采用保守策略；
- 动态 OCR 并发目前配置安全上限，但核心按页串行以降低内存峰值；
- 自动更新未实现；不会通过自动脚本绕过 macOS 安全确认。

任何限制都不允许静默丢页：无法提取的可见页面会在 Word 中留下核对提示，并计入转换完成状态中的问题统计。
