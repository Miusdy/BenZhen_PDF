# 隐私说明

本真 PDF 默认且当前仅在本机处理文件：

- 不上传 PDF、图片、文字层、OCR 结果、DOCX 或报告；
- 不调用云端 OCR、远程 API、CDN、广告、分析或追踪服务；
- 桌面应用不监听网络端口；
- 日志记录文件名、页码、阶段、计数和错误类型，不记录正文；
- PDF 密码不写入日志、配置或中间状态；
- 临时文件位于输出目录下的应用专用隐藏目录或用户指定的临时目录；
- 仅清理可识别的应用临时目录，不删除输入 PDF 或用户输出；
- 卸载应用不会删除用户输出的 DOCX 和报告。

开发者使用 `pnpm`、`pip` 或系统包管理器安装依赖时可能访问软件仓库，这与文档转换无关。正式运行应用不需要网络。
